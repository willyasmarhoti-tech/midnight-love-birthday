# Midnight Love Birthday — multi-halaman

## Buka di VS Code
1. Ekstrak ZIP.
2. Di VS Code pilih File > Open Folder lalu pilih folder ini.
3. Buka `index.html`; gunakan ekstensi Live Server dan klik Go Live untuk preview.
4. Tambahkan foto kalian ke folder `assets` dengan nama `foto-kalian.jpg`.
5. Tambahkan musik yang boleh digunakan ke `assets/musik.mp3`.

## Publikasi gratis dengan Netlify
1. Pastikan `index.html`, `style.css`, `script.js`, dan folder `assets` berada di root folder situs.
2. Buka https://app.netlify.com/drop dan login/daftar.
3. Unggah folder situs mengikuti instruksi di layar.
4. Setelah deploy sukses, salin URL publik dari Netlify dan buka di HP untuk menguji.
5. Siapa pun yang memiliki URL dapat membuka website. Jangan unggah foto pribadi tanpa persetujuan semua orang di foto.

Catatan: Musik dimulai setelah pengunjung menekan tombol karena browser membatasi autoplay. Gunakan hanya musik yang kamu punya izin untuk gunakan.
